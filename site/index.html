Install

Recommended: the Vercel skills CLI. npx skills is Vercel's open installer for agent skills. One command installs one tool for all your projects:

npx skills add Aboudjem/sniff -g

Works in more than 70 agents: pick yours in the menu (supported agents). In a terminal it shows the agent menu. In a script it installs into every agent folder, so add -a <agent> there. Only this project: drop -g. Use the tool's repo name below, and see its page on skills.sh.

Claude Code plugin. Add the list once, then install by name. For sniff, ui-ux-suite and recap-studio, the plugin also adds the MCP server.

claude plugin marketplace add Aboudjem/10x
claude plugin install sniff@10x

The nine plugins

sniff Apache-2.0

Find what is broken in your running web app before users do. Each page bug comes with the steps to repeat it and a fix.

npx skills add Aboudjem/sniff -g
claude plugin install sniff@10x

Works in more than 70 agents

Every plugin here ships as skills, which are Markdown files your agent reads. That is why all nine install outside Claude Code through npx skills add. Three also run as a standalone MCP server, the protocol an editor speaks to reach an outside tool: sniff and ui-ux-suite straight from npm, recap-studio straight from GitHub. The other six ship no MCP server. Per-editor snippets live in each repo's docs/editors.md.

The 10x bar

Every plugin here is held to an explicit eight-point quality bar: no dependency it does not need, a one-command install with no signup, CI that asserts behaviour, an install path outside Claude Code, a release this quarter, and no telemetry. ui-ux-suite and the six skills ship no runtime dependency; recap-studio's packages pull zod, its web app Next and React; sniff depends on zod only and downloads its browser engine and Chromium on first use (about 440 MB). If a plugin stops passing, it gets removed. The full checklist, with the roster and the verification runs behind it, is in QUALITY-BAR.md.
