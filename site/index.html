The nine plugins

sniff Apache-2.0

Walks your running app in a real browser and lists what is broken: dead pages, console errors, broken forms. Each page bug comes with repro steps and a fix.

Works with any AI editor

Every plugin here ships as skills, which are Markdown files your agent reads. That is why all nine install outside Claude Code through npx skills add. Three also run as a standalone MCP server, the protocol an editor speaks to reach an outside tool: sniff and ui-ux-suite straight from npm, recap-studio straight from GitHub. The other six ship no MCP server. Per-editor snippets live in each repo's docs/editors.md.

The 10x bar

Every plugin here is held to an explicit eight-point quality bar: no dependency it does not need, a one-command install with no signup, CI that asserts behaviour, an install path outside Claude Code, a release this quarter, and no telemetry. ui-ux-suite and the six skills ship no runtime dependency; recap-studio's packages pull zod, its web app Next and React; sniff depends on zod only and downloads its browser engine on first use. If a plugin stops passing, it gets removed. The full checklist, with the roster and the verification runs behind it, is in QUALITY-BAR.md.
