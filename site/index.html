A curated marketplace of developer tools for Claude Code. No bloat. Tested. Works in any AI editor.

View on GitHub See the plugins Quality bar

Add the marketplace once

claude plugin marketplace add Aboudjem/10x

Then install any plugin by name with claude plugin install <name>@10x. Each tool plugin also ships a one-line install.sh for other AI CLIs.

The seven plugins

sniff Apache-2.0

AI-powered QA that walks your running app like a user, discovers its flows, and finds real bugs across accessibility, performance, and broken interactions. A source scan is also available via sniff scan.

claude plugin install sniff@10x
curl -fsSL https://raw.githubusercontent.com/Aboudjem/sniff/main/install.sh | bash -s codex
GitHub npm: sniff-qa Pages demo

ui-ux-suite MIT

Design audit tool that scores a project across 12 dimensions and cites the named UX law behind every finding, with primary-source citations. WCAG, APCA, OKLCH color science. Zero dependencies. It audits, it never edits.

claude plugin install ui-ux-suite@10x
curl -fsSL https://raw.githubusercontent.com/Aboudjem/ui-ux-suite/main/install.sh | bash -s codex
GitHub npm: ui-ux-suite Pages demo

recap-studio MIT

Turns any topic or coding session into a clean, mobile-first one-page explainer you can read offline in about 5 minutes. Output is a self-contained, offline HTML page; deterministic heuristic checks validate clarity, accessibility, and structure before you ship.

claude plugin install recap-studio@10x
curl -fsSL https://raw.githubusercontent.com/Aboudjem/recap-studio/main/install.sh | bash -s codex
GitHub Architecture Pages demo

aws-cost-audit MIT

Read-only, evidence-first AWS cost audit. Reads your live AWS account, attributes every dollar, finds idle, orphaned, and over-provisioned resources, verifies prices live (never hardcoded), and ships a safe, reversible, gated savings plan with confidence levels. A Claude Code skill (no MCP server).

claude plugin install aws-cost-audit@10x
curl -fsSL https://raw.githubusercontent.com/Aboudjem/aws-cost-audit-skill/main/install.sh | bash -s codex
GitHub Pages demo

goalify MIT

Sets up a big coding task to run on its own. Scopes the work, locks the few real decisions, and writes the brief (a file the run works from) plus the condition (one line you paste into /goal), so a fresh full-context session executes the whole job, quotes the passing checks in its closing turn, and archives the brief to .goal/done/. A Claude Code skill (no MCP server).

claude plugin install goalify@10x
/goalify <your task>
GitHub

humanizer MIT

Detects 55 AI writing patterns and rewrites text to read like a human wrote it. Measures burstiness and produces a 0-100 AI-tell score. Five voice profiles (casual, professional, technical, warm, blunt) and three modes: detect (scan and score only), rewrite (full transform, default), and edit (in-place file edits). Pure Markdown, zero dependencies, no network calls. A Claude Code skill (no MCP server).

claude plugin install humanizer@10x
/humanizer "your text" [--mode detect|rewrite|edit] [--voice casual|professional|technical|warm|blunt] [--score]
GitHub

loopify MIT

Hands off a job that repeats: babysitting a release PR, watching a deploy, sweeping new bug reports. Writes the brief (a standing file the loop re-reads at the start of every tick) plus the line (one short string you paste into Claude Code's built-in /loop), with a tick cap, a stop rule, and five safety rails. Every tick logs what it did to TICKS.md; what it cannot do safely waits in QUEUE.md. A Claude Code skill (no MCP server).

claude plugin install loopify@10x
/loopify <your recurring job>
GitHub

The 10x bar

Every plugin here passes an explicit eight-point quality bar: zero runtime dependencies, one-command install, real tests, dual mode (plugin and MCP server, where applicable), active maintenance, and no telemetry. If a plugin stops passing, it gets removed. The full checklist lives in QUALITY-BAR.md.
